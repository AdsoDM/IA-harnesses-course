# Criterios de revisión

1. **ID.** La afirmación cita un ID existente y ese documento fue consultado en esta revisión.
2. **Vigencia.** Si un documento declara sustituir a otro, prevalece el más reciente vigente; una afirmación basada en el sustituido se marca «fuente sustituida».
3. **Correspondencia.** El texto del documento dice lo mismo que la afirmación (cifra, unidad, sujeto). Una coincidencia parcial se marca «contradicha» con la diferencia.
