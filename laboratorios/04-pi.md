# 04 — Sesión y traza de Pi

Duración: 2 horas. Requiere Pi autenticado; no requiere shell del agente.

1. Inicia una sesión con herramientas de lectura como en el módulo.
2. Pide tres entregables del curso con rutas de archivo.
3. Repite en print y JSON, en sesión nueva.
4. Inspecciona el JSONL: localiza llamadas, resultados y texto final. Evita usar la sesión persistida como si fuera el flujo JSON: son formatos con propósitos distintos.
5. Cambia solo el prompt para exigir evidencia y repite tres veces.
6. Sin credenciales o además de ellas: repite la captura JSON con el modelo de guion, sin plantilla y con `/respuesta-documental`. Normaliza ambas con `normalizar_pi.py` y explica la diferencia en `tool_calls`.

Entregable: `entregas/04-pi.md` con invocación, modelo exacto (o `curso/guion`, identificado como simulado), diferencias y un fragmento sintético de traza. Las trazas completas se guardan en `trazas/`.

Aceptación: una lectura real respalda una afirmación; sabes qué salida consume un script; documentas fallos sin excluirlos. Si el modelo responde de memoria, repite pidiendo que consulte el archivo y demuestra la llamada.

Pregunta: ¿por qué una rama de `/tree` no equivale a `git switch`? Una cambia contexto conversacional; la otra mueve la referencia del código/documentación.
