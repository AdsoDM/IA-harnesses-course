# 05 — Contexto y skill propia

Duración: 2 horas. Parte documental offline; prueba de carga con Pi opcional.

1. Copia el bloque didáctico del módulo a un directorio de ensayo fuera de configuración global, por ejemplo `entregas/skill-practica/SKILL.md`.
2. Ajusta su descripción para que se active ante revisión de evidencias y no ante cualquier pregunta.
3. Añade una referencia con tres criterios: ID, vigencia y correspondencia entre afirmación/fuente.
4. Versiona ambos archivos en Git.
5. Si tienes Pi, cárgala explícitamente con `--skill ./entregas/skill-practica`; utiliza `/skill:revisar-evidencias` si necesitas forzar la carga. Recuerda que la carga automática exige que el modelo pueda usar `read`.
6. Redacta dos resúmenes de una conversación: uno pierde la regla de vigencia y otro la conserva. Explica la diferencia.

No uses documentos privados: inventa dos normas y sus fechas. El archivo de práctica pertenece a tu proyecto; no modifica las skills de otras herramientas (Pi, asistentes de IA de tu organización) ni se instala globalmente.

Referencia para después: [skill de ejemplo resuelta](../soluciones/lab05-skill/SKILL.md).

Aceptación: el procedimiento es reutilizable, sus referencias se resuelven, el trigger es preciso y el resumen conserva restricciones y fuentes. Entrega `entregas/05-contexto.md` y la skill versionada.
