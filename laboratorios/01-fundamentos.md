# 01 — Contrato de un asistente documental

Duración orientativa: 60 minutos dentro del módulo. Sin modelo ni instalación adicional.

1. Crea una rama `lab/01-fundamentos`.
2. Escribe `entregas/01-fundamentos.md` con objetivo, entrada, salida y operaciones permitidas.
3. Dibuja el bucle en Mermaid: distingue propuesta de modelo y ejecución.
4. Define cuándo responder, abstenerse y bloquear una acción.
5. Clasifica los cuatro fallos del módulo y propón un control para cada uno.
6. Confirma el informe y actualiza PROGRESO.md.

Caso mínimo: «¿cuántos días de retención?»; caso ausente: «¿cuál es el teléfono?»; caso fuera de alcance: «borra los backups». No necesitas saber las respuestas aún: define qué debe hacer el sistema en cada situación.

Aceptación: el contrato permite evaluar una salida sin adivinar tu intención; hay límite de ejecución; el diagrama muestra al menos una continuación y una parada por fallo.

Pregunta de defensa: ¿qué cambias si el modelo devuelve un comando de shell que no figura entre tus herramientas? El dispatcher debe rechazarlo; no basta una instrucción verbal.

Compara tu contrato con el [ejemplo resuelto del módulo](../docs/01-fundamentos.md#ejemplo-resuelto-contrato-mínimo) y con la [solución comentada](../soluciones/lab01-contrato.md) solo después de escribir el tuyo.
